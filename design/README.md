# Cadence Loop

A C-shaped loop suggests the app's name, a record groove and repeating rhythm. The play triangle makes the music-player purpose legible at launcher size. The open right side gives the mark some movement without fine detail.

- Background: deep teal `#0F1D20`.
- Loop: mint `#A5E8CC`.
- Play: soft white `#F2FFF9`.

`cadence-loop.svg` is the editable vector master. Android uses separate foreground, background and monochrome vector drawables, with the mark kept inside the adaptive icon safe area. No raster image is required by the app.
