# Binary distribution

The committed APKs and checksum files are release artifacts. Cadence 2.5.0 includes the signed update and the earlier explicitly labelled unsigned handoff APK; the signed build is also attached to GitHub Release `v2.5.0`. Historical signed APKs and their checksums remain unchanged. Future signed APKs should be attached to GitHub Releases, with checksums and release notes, rather than added to the Git repository. This keeps clones smaller while preserving signed, verifiable downloads.
