# Binary distribution

The committed APKs and checksum files are release artifacts. Cadence 2.5.0 includes the signed update and the earlier explicitly labelled unsigned handoff APK; signed builds are attached to their matching GitHub Releases. Historical signed APKs and their checksums remain unchanged. The 2.5.1 APK is retained only because the tag-driven release workflow publishes its already-verified binary; future release automation should move signing into GitHub Actions so binaries no longer need to be added to the repository.
