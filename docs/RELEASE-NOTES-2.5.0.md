# Cadence 2.5.0

Cadence 2.5 introduces one coherent light and dark design system across the phone UI and widget. It adds large titles, grouped settings, pill controls, a four-tab Home/Search/Library/Profile bar, redesigned discovery and library surfaces, contrast-safe artwork tinting, a sleep timer and access to Android's equalizer for the active playback session.

Queue editing, crossfade, podcast speed, downloads, Android Auto, the widget, Google Drive continuity and backup formats are retained. The package name and signing configuration are unchanged. No new permissions, database migrations, backup fields or sync payloads are introduced.
