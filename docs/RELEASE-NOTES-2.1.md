# Cadence 2.1

Optional Google profiles and hidden Drive library sync, playlist download-all, a circular green offline badge and per-episode podcast progress with round play/pause controls.

Install over 2.0/2.0.1 without uninstalling. Package and signing certificate are unchanged; version code is 7. The original 0.3.1 release still requires the verified backup migration described in README.

Tap the profile photo beside Cadence to sign in. Choose **Merge this library** to include this phone's library, then allow hidden Cadence Drive storage. Sign-in is optional. Sync includes library metadata and desired downloads, not audio files. Use **Saved downloads → Download all** to fetch audio on another phone.

Google Cloud publishing status is In production with basic identity and drive.appdata only. A real Google-enabled phone sign-in/Drive round trip and two-phone continuity check remain necessary; automated tests use synthetic libraries rather than personal Google accounts. No Play Protect certification is claimed.

See VERIFICATION.md for the recorded checks and PRIVACY.md for data handling.
