# Cadence 2.5.1

Cadence 2.5.1 is a visual polish update for the Apple-inspired Android design introduced in 2.5.0. It refines typography and grouped lists, adds edge-bleeding shelves and filter rows, and simplifies the translucent mini player and tab bar. The mini player now includes Next, while duplicate queue actions have been removed.

Home gains a more useful Continue listening treatment and clearer shelf subtitles. Search has a centred, card-free suggestion state. Library moves playlist creation into the title bar and import into its overflow menu. The full player uses larger artwork, an artwork-to-black gradient, a cleaner transport row and podcast-only skip controls. Profile sync now shows an in-progress spinner or a concise last-synced confirmation.

Playback, downloads, Android Auto, media sessions, Google Drive sync, backups and database formats are unchanged. This release adds no permissions or data migrations.

## Download

Download `Cadence-2.5.1.apk` from this release and verify it with `SHA256SUMS-2.5.1.txt`. The APK uses the retained Cadence release certificate and version code 13, so it can update earlier release-signed Cadence installations in place.
